# Version 1.3 — Stage B: Create & Assisted Composition

Branch `feat/v1.3-create-assisted` is stacked on `feat/v1.3-discover-learn` at `76a0268`. Review Stage A against main; review this stage against Stage A. Neither stage is merged or deployed by this work.

## Use the editor

Open **Create** in the header. Name the piece, select a hand, measure, octave and duration, then insert a note or rest. Each hand appends independently to its next free beat; switching hands keeps its previous events. Piano taps preview by default. Enable **Write notes when I tap keys** for explicit step entry. The chord tray combines arbitrary notes into one simultaneous event; the optional chord picker uses the existing chord theory engine.

**What Comes Next?** offers at most three chord and three melody suggestions using deterministic local rules. Chords use tonal relationships and preceding harmony; notes favor nearby key tones and the other hand's sounding harmony. These are suggestions, not probability claims. Listen never writes. Choose a chord, then explicitly insert the whole chord or choose a tone and octave. Manual entry is always available. Insertion checks the selected hand's remaining measure duration and never replaces entries or automatically moves to another measure. Undo restores inserted/deleted events; deleting closes the gap, as explained beside the control.

The independent JSON document stores up to eight 4/4 measures, separate hand events, simultaneous pitch groups, rests, title, key and tempo. Whole, half, quarter and eighth durations are supported. Unfinished hand parts are identified; unwritten time stays silent without changing the source. Both hands share the same playback timeline and use the existing single audio engine and scheduler. Score highlights follow scheduled events.

## Saves, notation and printing

Compositions use new `compositions-v1` and `composition-draft-v1` storage keys through the existing storage helper. Existing progression saves and preferences are untouched. Save, reopen, confirmed duplication/deletion, working-draft restoration and validated JSON backup/import are available. Up to 50 compositions can be saved; backups are recommended because browser data can be evicted.

The old fixed-pattern SVG renderer could not represent independently timed hands and rests. A small separate score renderer now supports this bounded editor and guided studies; Explorer notation remains unchanged except exporting its existing clef helper. It renders conventional clefs, note/rest durations, written accidentals and naturals, ledger lines, aligned beats and optional note names. Key is a suggestion context: accidentals are engraved explicitly rather than using key signatures. No notation dependency was added. Advanced notation, ties, tuplets, dynamics, articulations, MIDI and recording remain outside this MVP.

The selected measure is shown by default; Show the whole score reveals all measures. Print uses browser printing with all measures, both hands and the title, without editing controls or backgrounds. Chromium's actual print PDF was inspected and checked for both hands and absence of controls. This is browser printing, not a standalone PDF-export feature. iPhone Safari's print dialog, pagination and AirPrint still require physical-device testing.
