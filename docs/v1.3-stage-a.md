# Version 1.3 — Stage A: Discover & Learn

Branch `feat/v1.3-discover-learn`, based on main `98bad2c` (merged 1.2.1).

- Removes only the focus outline on the noninteractive main container. Keyboard controls retain visible neutral focus; validation and playing/selected highlights remain.
- 18 presets retain the original five and add keys, moods, complexity, inversions and a straight-time 12-bar blues. Browse & Play provides filtering, Hear and Play along. My progressions manages personal saves; the complete legacy preset picker is available separately inside Browse.
- Unsaved custom sequences are backed up in a separate `sequence-drafts` collection before loading a preset. Failed backups block replacement; up to 20 drafts are kept, with latest-draft recovery in My progressions. Existing saved sequences and storage keys remain intact.
- Four guided studies develop a single-hand shape, major/minor color, a held left-hand foundation and a four-harmony pattern. Study 4 is an original Bach-inspired arrangement, explicitly not a transcription of BWV 846. No copyright score is copied and no original-score accuracy claim is made.
- All new playback uses the existing player and gesture-unlock infrastructure. The audio engine and scheduler are unchanged. An independent small SVG score renderer handles aligned hand events, durations, rests and written accidentals; Explorer rendering is preserved (only its existing clef helper is exported).
- No runtime dependency, network service, AI API, fabricated history or grading is introduced. All content and code are cached under `jlk-studio-v1.3-a`.

Checks: Node preset/draft/study tests plus existing theory/audio/scheduling suites; browser discovery/filtering/preview/play-along, draft recovery, four-study playback and offline checks; existing navigation, progression graph and offline-worker suites. Screenshots: [Browse](screenshots/v1.3-a/browse-mobile.png), [Guided studies](screenshots/v1.3-a/guided-studies-mobile.png).

Physical iPhone audio, VoiceOver, native forms and Home Screen update checks remain unverified for this patch. No merge or deployment. API PR creation was previously denied; no denied route is retried or credentials broadened.
